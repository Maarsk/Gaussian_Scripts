Small collection of QOF scripts i developed for Gaussian16.
GetTest -> Geometry extraction from .out file, output are Minmovie.xyz which contains all optimized geometry (works for scan) and movie.xyz which contains all geometry
GetOScillationTD -> All oscillation strenght and amplitudes obtained from TD-DFT calculation
GetPlusMinus -> Small script to avoid falling into TS geometry, generates two .xyz before and after the TS
